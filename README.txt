RUN PANNURA VIDHAM
1) Python install irukanum (python.org)
2) Folder kulla Terminal/CMD open pannu:
      pip install -r requirements.txt
      python manage.py runserver 0.0.0.0:8000
   (Windows-la run.bat double-click pannalum podhum)
3) Browser: http://localhost:8000
